# weather-map-germany

Separates Projekt für die Deutschland-Wetterkarte (V1).

## Struktur

- `frontend/` React + TypeScript + Vite + OpenLayers
- `bff/` Node/Fastify BFF mit V1-Endpunktgrundlage
- `docs/` Planungs- und Entscheidungsdokumente
- `samples/` optionale Beispielpayloads externer Quellen

## Schnellstart

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### BFF

```bash
cd bff
npm install
npm run dev
```
