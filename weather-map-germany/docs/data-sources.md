# Datenquellen (V1)

## Primärquellen
- Radar: DWD WMS/WMTS (`https://maps.dwd.de/geoserver/ows`)
- Stationen/Aktuelle Werte: DWD API/Open Data
- Forecast (stündlich/täglich): Open-Meteo (DWD ICON)
- Pollen: DWD Open Data (spätere Phase)

## Reihenfolge
1. Radar + Stationen + Current Observations
2. Hourly Forecast
3. Daily Forecast
4. Pollen
