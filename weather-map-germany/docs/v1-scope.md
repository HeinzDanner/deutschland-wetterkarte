# V1 Scope

## Enthalten
- Deutschlandkarte
- Modus "Wetter jetzt"
- Radar-Layer
- Stationsdarstellung + auswählbare Stationen
- aktuelle Messwerte im Detailbereich
- Zoomabhängige Sichtbarkeit
- Lade-/Fehlerzustände + Quellenhinweise

## Nicht enthalten
- GeoServer/GeoWebCache/PostGIS
- historische Wetterdaten
- komplexe Nutzerverwaltung/Auth
- große Multi-Source-Abstraktion
